# Scratch Baseball Game

To play click [here]([https://claracruet.github.io/Coding_Projects/Scratch_basebal_game/))

My CS50x Scratch project.

## How to Play
Enter the batter's name.
Move the mouse to aim the batter.
Press SPACE to swing.

## Features
- Randomized pitches
- Hit and foul zones
- Animated batter and pitcher
- Custom Scratch blocks
- Variables, loops, conditions, and broadcasts
